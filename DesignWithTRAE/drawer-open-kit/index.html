①三级能力模型（L0 / L1 / L2）

内置功能保持默认为 L0；L1 让宿主替换内置抽屉的内容层；L2 让宿主新建抽屉。三者均不做新增鉴权。

L0默认UI（现状保留）

AI回复 / 素材库 现有固定界面与交互，作为开关关闭时的默认抽屉体验，视觉与行为零变化。

L1内置抽屉 · 自定义UI交互

Manifest 增加「自定义UI交互」开关（默认关）。开启后 SDK 仅保留抽屉基座（容器/返回/关闭），基座头部完全复用现抽屉视觉（返回/关闭位置不变），返回按钮显隐可由宿主经 setBackVisible 配置（默认显示）；内容层由宿主自绘，并可调用抽离出的能力字段。

L2自定义抽屉（新建）

宿主运行时注册新抽屉（id/标题/入口图标/内容工厂），数量上限 4 个。入口自动进入工具面板宫格末尾 + 顶部工具条（受定制工具栏排序/显隐管理）。

②抽屉基座 与 内容层 解耦结构

将现面板头部的「返回/关闭」上移为基座标准头部；内容层成为可替换插槽。

SDK 抽屉基座（保留）
  • 抽屉容器：80% 屏高 / 开合动画 / 下拉手势关闭
  • 标准头部：返回（宿主经 setBackVisible 配置显隐，默认显示）+ 标题槽 + 关闭（恒显）
  • 返回键分发：先内容层后基座
  • 生命周期回调：opened / closed / back
  • 主动开合：openDrawer(id) / closeDrawer(id)
  • 状态栏安全区 / 主题查询
＋
内容层（可替换插槽）
  • L0：SDK 默认UI（还原现状视觉）
  • L1：宿主自定义UI（AI回复/素材库）
  • L2：宿主自定义抽屉内容（空白基座交付）
  • 宿主可调用能力字段 API 重排功能
  • 异常时基座捕获并降级，不影响键盘主链

⑤标准产品流程

5.1 L1 集成配置流程

① 勾选功能集成模板勾选 AI回复 / 素材库
→
② 勾选开关Manifest 写入 enable*CustomUi（默认 false）
→
③ 初始化OemImeSdk.initializeFromManifest
→
④ 注册工厂setDrawerContentFactory(id, factory)
→
⑤ 生效开+已注册→宿主内容；否则降级 L0

5.2 客户示例：倒计时→关抽屉滑屏→截图发模型→再拉起抽屉（L1 能力映射）

1
用户点击键盘「AI回复」按钮，基座抽屉弹起SDK入口
2
宿主内容层渲染倒计时卡片（自绘UI）宿主
3
调用 controller.closeDrawer() 主动关闭抽屉，宿主执行滑屏宿主
4
截图并发送大模型：可调用 ai_reply 识屏/极速能力，或宿主自有模型宿主
5
调用 openDrawer("ai_reply") 再拉起抽屉宿主
6
宿主自绘等待/结果页，或经结果回调渲染回复建议宿主

5.3 L2 自定义抽屉接入流程

① 初始化SDK 初始化成功（无需鉴权）
→
② 注册registerCustomDrawer(id/标题/图标/工厂)，上限 4 个
→
③ 落位宫格追加末尾；工具条未满6默认显示、已满进隐藏池
→
④ 可管理定制工具栏排序/显隐（含自定义项）
→
⑤ 使用点击入口→基座抽屉→宿主内容

5.4 降级与容错

场景行为
开关开 + 未注册工厂降级 L0 默认UI，warn 日志
宿主内容抛异常基座捕获：内置抽屉降级 L0 / 自定义抽屉关闭，回调 onHostContentError
旧宿主 + 新 SDK无开关无注册，完全 L0，零影响
注销自定义抽屉入口即时移除 + SP 持久化清理（custom_<id>）

⑥能力字段协议总览（交付宿主的字段清单）

字段与 UI 解耦：宿主可任意排版以下字段，并经对应 API 触发底层能力。完整入参/回调见方案文档 4.2.3 / 4.2.4。

AI回复（12 字段）

点击复制生成回复ai_reply.entry.paste 极速生成ai_reply.entry.fast 识屏回复ai_reply.entry.ocr 传图回复ai_reply.entry.image 截屏权限申请ai_reply.permission.screen 相册选图ai_reply.picker.album 生成进度时间轴ai_reply.progress.timeline 回复建议列表ai_reply.result.list 语气切换ai_reply.result.tone 重新生成ai_reply.result.regenerate 模型声明文案ai_reply.meta.footer 受限态ai_reply.state.restricted

素材库（11 字段）

分类页签material.tabs.category 文档子分类material.tabs.file_sub 搜索material.search 素材列表material.list 预设文件夹material.folders 发送素材material.action.send 附件预览material.action.preview 悬浮添加material.fab.add 创作器material.composer 远程素材同步material.remote.sync 状态位material.state.*

⑦鉴权 与 R8 边界

不做什么

L1/L2 均不新增 license capability，不走我方鉴权开通；
宿主自研代码不纳入 SDK-R8 加密输入；
基座不对宿主内容做业务校验。

要做什么

DrawerKit 公开 API 加入 oem-ime-sdk-core 的 proguard keep 与 consumer-rules（宿主侧 R8 不误删）；
L1 能力调用仍受既有企业开关约束（事实状态）；
更新 02-分发与加固方案 的开放层 keep 清单。

Manifest 新增开关：com.paopaoime.oem.enableAiReplyCustomUi / com.paopaoime.oem.enableMaterialLibraryCustomUi（默认 false）

已确认产品规则：自定义抽屉数量上限 4 个（超出注册返回 QUOTA_EXCEEDED）；工具条维持 6 个上限（自定义项占配额，已满进隐藏池）；自定义图标默认原色渲染、不跟随内置 tint；L1 基座头部完全复用现抽屉视觉（返回/关闭按钮位置不变），返回按钮显隐由宿主经 setBackVisible 配置（默认显示）。

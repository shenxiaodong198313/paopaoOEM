# 2026-10-12 快捷回复皮肤面板与键盘调节

## 授权与范围

用户已验收 Skin Lab 夜幕石墨、日光瓷白及全皮肤面板方案，要求同步 Android 并重制、发布 OEM SDK。本轮明确允许同版本发布、无需回归测试；后续补充键盘高度/宽度调节失效修复，以及默认标准按键声音、50% 音量、较强触感。

SDK 保持 `1.0.0.202610111`，运行时保持 `org.fcitx.fcitx5.android:app:1.12`。本轮不更改模型配置和客户自绘抽屉接口。

## 实现

- 快捷面板独占原 preedit + 工具栏区域，原工具栏隐藏，标准皮肤不增加键盘总高度。沿用当前皮肤工具栏材质；标题、输入文案、按钮自动匹配并调整对比度。
- 左上气泡星光标题、右上关闭；底部文案单行省略，右侧生成星光按钮。按钮上、下、右统一 3 设计单位，同一像素换算确保等距。
- 关闭/粘贴/打字/收起消费以及同宿主限制保持；OEM AI 门禁关闭时不展示生成入口。
- 拖动草稿和显式保存的几何配置优先于皮肤默认尺寸，直接拖动达到 touch slop 即开始，无需等待长按。取消恢复保存前状态，重置清除当前方向的覆盖值并恢复皮肤默认尺寸；设计单位与实际宽度使用同一密度。
- 默认启用标准按键音、音量 50%。OEM 携带与泡泡同源的按键音资源；静音/振动模式保持不播放声音。触感采用设置页第 5 档“较强”：28ms / amplitude 210。仅修改默认值及主动恢复默认设置，不迁移覆盖已有用户选择。

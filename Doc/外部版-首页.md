# 外部版首页

## 适用对象

- 集成厂家研发
- 集成厂家的技术负责人
- 需要快速判断可接入能力、交付边界和授权方式的合作方

## 当前对外交付范围

- 第一阶段交付形态为 `AI Runtime SDK AAR + 集成文档 + 授权参数 + demo-app`
- 当前目标不是交付完整 OEM 工程源码，而是交付稳定的可复用能力模块
- 对外 HTML 文档统一部署在 `https://www.paopaoime.com/oem`

## 对外提供内容

- SDK 集成手册
- API 参考
- 授权与交付说明
- 版本说明
- FAQ 与排障

## 对外不提供内容

- 内部防破解实现细节
- 完整授权风控规则
- 私钥、签名策略和服务端内部模型
- 内部调试入口、实验开关和研发壳工程

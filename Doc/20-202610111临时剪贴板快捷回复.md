# 2026-10-11 临时剪贴板与高情商快捷回复

## 用户需求与范围

泡泡主项目九项实机验证通过后，用户授权同步 OEM。客户模型配置、配置文件和客户自绘抽屉扩展仅限 OEM。新需求替代上一版「复制完全不替换工具栏」：当前宿主的新复制事件在候选区展示一次；不读取启动时剪贴板历史，不跨宿主重放。

- 已开键盘直接展示，隐藏时复制在首次唤起展示；左图标、中间内容、右侧关闭，右上高情商回复。
- 关闭只清除临时展示；打字让位候选词；展示后收起、宿主切换均消费。未展示的同宿主原生文本选区转回编辑器可以保留。
- 快捷入口收起键盘，直接使用现有结果抽屉；生成调用已有粘贴回复管线，不走三步智能体检查；选中只填入原宿主草稿，不执行发送。
- AI 功能关闭或缺失相关切片时不显示快捷回复按钮；授权、隐私输入框与敏感剪贴板按既有规则处理。

## OEM 自定义与配置

快捷调用仍经 `AiCommunicateReplyService.generateReplies` 和现有 `OemEnterpriseConfig`：客户模型模式、域名/直连、HOST_ONLY/DUAL_WRITE、提示词、语气、超时、错误文案继续同源，无独立配置文件或硬编码模型。

DrawerKit 延用 `DRAWER_AI_REPLY` 和客户注册工厂。新增 `OemClipboardReplyState`、`onClipboardReplyStateChanged`、controller 的 `clipboardReplyState / regenerateClipboardReply / insertClipboardReply`。支持内容层及整块自绘；状态在 View 创建后重放，晚完成结果也能收到。失败工厂降级已有内置结果页。自定义 UI 的旧 `sendReplyToInput` 在快捷会话内同样仅填草稿。

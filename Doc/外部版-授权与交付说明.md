# 外部版授权与交付说明

## 标准交付模式

- 当前标准交付版本以授权预留字段接入为主
- 私有化客户使用离线授权或私有 License Server
- 授权默认和厂家、宿主包名、签名信息绑定

## 标准在线授权

- `customerId`、`appKey`、`licenseProvider` 当前属于预留字段/预留接口
- 客户现阶段可先按占位参数完成集成与联调
- 若需正式在线授权能力，需按专项交付启用并替换为正式参数与实现
- 正式上线后可扩展授权续期与状态管理

## 私有化授权

- 可提供离线 License 文件
- 也可提供部署在客户内网的 License Server
- 私有化客户的续期、扩容和功能变更通过更新 License 完成，具体以专项交付版本为准

## 计费建议

- 标准客户可采用年费授权
- 计费口径可按活跃设备席位或活跃用户席位执行
- 最终合同口径以商务约定为准

## 对接时需要确认的事项

- 交付环境是公网还是内网
- 是否具备在线授权请求能力
- 是否需要按用户统计
- 是否需要自动化等高级能力
- 是否要求单独签署私有化 License 协议

## 续费与升级

- 续费后我方更新授权状态或下发新 License
- 升级 SDK 时以版本说明和迁移指南为准
- 过期、停用和降级策略会在合同中约定

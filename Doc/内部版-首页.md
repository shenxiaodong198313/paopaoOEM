# 内部版首页

## 适用对象

- 你自己
- 后续参与 OEM SDK 改造的研发同学
- 需要掌握真实模块边界、授权链路和交付方式的人

## 当前内部基线

- 第一阶段 SDK 化以 `OEM/android/aikeyboard-sdk-ai` 为起点
- 第一阶段目标是先形成可发布、可集成、可文档化的 `AI Runtime SDK`
- `OEM/android/app` 暂时继续承担内部验证壳和 demo-app 角色
- 输入法核心、授权壳、自动化和 UI 仍按分层方案继续抽离
- 对外资料统一收敛到 `website/oem`，由 `https://www.paopaoime.com/oem` 提供访问

## 内部交付原则

- 对外只交付公开 API、AAR、License、版本说明和 demo-app，不交付完整源码
- 工程真实改造顺序必须遵循“先 AI Runtime，再 Core，再 UI/Automation”的节奏
- 能力边界和宿主职责必须写入文档，再做代码抽离
- 所有 ECS 部署路径、上传命令和访问地址都以仓库文档为准，不以口头约定为准

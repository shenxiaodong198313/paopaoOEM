# 1.0.0.20260921 本地默认皮肤发布与集成验收

范围：OEM 本地默认皮肤、输入法运行时、统一 SDK、官网 Wiki、集成 MD/PDF 与独立企业宿主。

## 实现

- 浅色：日光瓷白；深色：夜幕石墨。JSON 与 PNG 随 Fcitx runtime AAR 内置到 assets/system_themes。
- 运行时由 app:1.6 升至 app:1.7；七个公开 SDK 统一为 1.0.0.20260921。
- 同步 2.9 皮肤解析、图片切片和键盘/候选栏/侧栏渲染。保留 OEM 授权门禁、企业抽屉和其他输入行为。
- 旧默认主题迁移为新皮肤；保留自定义主题、显式跟随系统设置，以及旧安装未显式保存时的跟随系统默认值。
- 内置资产使用设备加密存储，支持首次解锁前加载；禁止删除和覆盖内置皮肤。

- 工具栏按用户反馈移除常驻圆底，保留点击区域和 Ripple；修复 OEM 内边距叠加导致 23dp 图标缩小到约 13dp 的问题。

## 过程中修复的问题

- Kotlin 测试 Instrumentation 引用的 `joinToString$default` 被宿主 R8 优化，改用 Java 测试，不关闭或弱化正式宿主的 R8。
- Instrumentation 开始执行早于 Application 初始化，测试入口增加 `waitForIdleSync()`；正常 App 启动不出现该测试竞争问题。
- 全量刷新依赖后腾讯 Maven 镜像返回 Capsule 元数据但缺 AAR，独立工程对 `com.github.Kyant0:Capsule` 使用 JitPack exclusiveContent，并补充 SOP 镜像注意事项。官方 JitPack AAR 已确认可取得。

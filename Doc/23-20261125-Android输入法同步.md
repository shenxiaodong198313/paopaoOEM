## 分模块组装

- `oem-ime-sdk-core` 延续初始化、授权、能力注册和宿主接口契约。必选 `oem-ime-host-bridge` 提供键盘、设置页和 OEM 宿主桥。
- `ai-ime/host-bridge` 发布为输入法运行时 `org.fcitx.fcitx5.android:app:1.14`，携带中文手写模型、输入事件和候选、动效渲染、词库路由及随包白霜。五个内部 Fcitx 原生／公共运行时坐标一起升至 `1.1`。本版采用独立坐标，详情见 [上游锁定](../android/ai-ime/oem-upstream-lock.json)。
- 动效入口在按键效果页提供「皮肤默认」「无动效」与 16 款预设。音效沿用原有七个 ID，在同一音效列表加入 23 款，已保存的合法音色继续使用。AAR 资源分别随输入法运行时和宿主桥进入 SDK 宿主。
- 语音继续由 `oem-ime-sdk-voice` 按需接入 sherpa-onnx。手写键盘随语音模块安装和启用状态显示长按语音入口。自动化、素材库、AI 回复和开发者功能沿用各自 SDK 切片，DrawerKit 自定义入口和剪贴板回调由原 OEM 宿主分支处理。
- App 与 SDK 宿主公用词库设置 Fragment。白霜为 `aaf88ecfb65338ed809e3bee176f7b8f98c363ab`，Android 数据版本 `926c4bb631fe25e08bd553795ac06a3ee3b208bdbe3d8eff8d3ed04fc1bffb23`。Release 或 Debug 打包在生成目录合并预编译资源和 Fcitx 配置；雾凇和 Rime 按原下载协议取得并校验。切换到 Rime 后显示五笔和五笔拼音。
- 后续词库同步以泡泡本端已验证的 Android 预编译目录为输入。更新 `precompiled-rime`、`offline-dictionaries` 及已发布可选包清单时，核对同一批次的原生接口、22 项白霜文件摘要和版本身份，重新构建基础宿主并检查新旧切换。

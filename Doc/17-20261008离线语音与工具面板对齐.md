# 20261008 离线语音与工具面板对齐

## 发布内容

- SDK `1.0.0.20261008`，Fcitx runtime `app:1.9`，演示包 `versionCode 202610080` / `versionName 1.0.0.20261008`。
- 语音独立为可选 `com.paopaoime.oem:oem-ime-sdk-voice:1.0.0.20261008`；只有该模块传递引入 `com.paopaoime.oem.internal:sherpa-onnx:1.13.8`。基础输入法无语音实现、sherpa JNI 或麦克风权限。官网选择器默认不勾选可选模块；完整演示包主动集成语音，集成后 JSON 默认开启。
- 三档固定模型：性能 101,874,904 字节、均衡 242,880,118 字节、质量 846,750,000 字节，各自包含共用的 75,519,198 字节标点模型；权重不进入 APK。默认性能档，已有用户选择优先。
- 工具栏、工具面板、空格长按语音动作、输入法设置使用同一可选桥接。波带面板、实时文字、停止、光标取消、隐藏与内存回收沿用泡泡实现。
- 宿主 `res/raw/oem_voice_config.json` 可覆盖总开关、默认档位、线程、解码、端点、录音时限及下载镜像。固定 SHA-256/字节数校验；更换 URL 不允许悄悄替换模型架构或权重。非法配置禁用语音并保留普通键盘。
- 日光瓷白/夜幕石墨使用当前泡泡图标及 23dp 尺寸；面板随皮肤调整图标、文案和卡片对比度，矮键盘两行文案保持完整。OEM 自定义抽屉与企业授权入口保留。

## 构建与依赖隔离

1. 重置旧输出后按 SOP 三阶段构建：Fcitx 六模块 → OCR、Stellar 九模块、sherpa → 八个公开 SDK。
2. 八个公开 SDK 完成 Release/R8；语音独立使用内部混淆包名，避免单独 R8 后生成的 synthetic 类与 host-bridge 重名。JNI、可选 Provider 与跨 AAR 接口由 consumer rules 保留。
3. 全仓 25 AAR，catalog/交付清单显式列 24 项，另有内部传递依赖。每项都有 AAR/POM/module。只有 voice 的 POM/module 引用 sherpa。
4. 官网演示 APK 使用 `OEM/demo/android` Debug 构建；另建独立 Release/R8 宿主，未引用 OEM 源码工程。
5. 同一 ARM64 full 宿主对照：移除语音依赖约减少 9.1 MB APK。未集成宿主没有 `libsherpa-onnx-jni.so` 和 `RECORD_AUDIO`；完整宿主仅有一份该 JNI，不含 `.onnx` 权重。配置关闭只隐藏/停用功能，不减少已集成框架的体积。

## 真机验证

设备：OnePlus PLQ110 / Android 16。使用独立验证包和本地输入框，关闭企业输入质检会话上传。

- 无语音 SDK、已集成但 `enabled:false`：两套独立 Release/R8 宿主均通过，普通键盘可用，语音入口隐藏。
- 配置/文本边界：配置默认与覆盖、范围/解码/HTTPS 校验，以及组合文字修订、最终标点、光标与连接隔离，合计 6 项通过。
- 输入法设置内的语音页进入/返回、永久拒绝麦克风后的系统设置提示与取消返回均通过（独立 R8 宿主 2 项用例）。
- 真实设置页下载三档：暂停/续传、三档切换、全部模型大小/SHA-256 验证通过；未向应用目录注入模型权重。
- 断网固定 PCM：三档都正确识别中文并自动标点；重复调用复用已加载模型；纯静音返回空文字。首轮冷启动约 835 / 1445 / 3146 ms，暖调用初始化均为 0 ms；设备与缓存状态会影响时延。
- 真实麦克风：关闭 Wi-Fi 和移动数据，手机扬声器播放同一固定 WAV，由 AudioRecord 实际采集，质量档完整转写“你好，欢迎使用泡泡输入法。今天下午三点，我们在会议室讨论项目进度，请帮我把这段话转换成文字。”；手动停止、再次启动、移动光标取消、隐藏键盘释放录音全部通过。网络与媒体音量在 finally 中恢复。
- 四类 Android 密码类型在实际 VoiceImeController 的录音前检查中全部被拒绝。该 OnePlus 的安全键盘会截获真实密码框并屏蔽截图，OEM 未收到新的密码 EditorInfo，因此此项是 controller 边界测试，不宣称已用该机覆盖 OEM 的真实密码框切换。
- 两套皮肤完整回归通过：QWERTY / T9 / 数字、英文 a / 中文你好 / 数字 5、工具栏图标 23dp、空闲透明背景、对齐、工具面板文字不裁切、语音入口存在、浅深色切换、旧皮肤迁移与自定义皮肤保护。
- 测试源码：`OEM/tests/voice/`；日志和截图：`tmp/oem-voice-20261008/`。AndroidJUnitRunner 所需的 Kotlin/tracing keep 只放在验证宿主，不进入公开 SDK。
